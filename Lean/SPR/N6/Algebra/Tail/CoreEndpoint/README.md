## 数学组织

设 `M=e+f+g`、`N=(e+f)M`、`G=f+g`。实际宽度坐标代换为

```
u = x + A*z + A^2*y
q = N*(z + (2*A+e)*y)
h = N*G*y
```

目标是完整五次式在 `x^i*y^j*z^k` 上的系数，`i+j+k=5`。
这里五次指宽度坐标的齐次次数；原问题的分子仍要求恰六次。
独立极化坐标 `u,q,h` 的正锥过大，不能直接假设极化系数非负。
`PureHigh/PureLow` 与早期混合项保留各自已审查的完整证明。

其余完整块使用准确的全间隙恒等式

```
E = F0 + f*F1 + f^2*R.
```

`F0`、`F1`由 `SmallGap/High0,High1,Low0,Low1` 中完整的小系数，
乘非负的二项式权重和 `(A+e)` 的幂得到。只使用这些小系数整体的非负性，
不声称它们的各个 `A` 系数非负。`R`保留正系数的Horner因子。
恒等式适用于所有参数；不是只在 `f` 很小时有效的展开近似。

## 一项完整证书的五个层次

以已完成的 `FullLow410` 为例：

1. `FullLow410Data.lean`定义各个A层的源、低阶因子和正余项数据，并证明余项非负。
2. `FullLow410Source.lean`定义同一个完整A多项式，便于独立核验源重建。
3. `FullLow410Identity0`至`Identity6`逐层证明无条件实多项式恒等式。
4. `FullLow410.lean`重新组装同一个A，再用两个完整低阶因子及余项的非负性。
5. `FullLow410Packet.lean`连接到 `lowOuter.c410`；`Synthesis/CoreLow410.lean`
   经实际参数传递和闭端点连续性接回原系数及综合链。

本轮分离的Source/Packet桥只负责恒等式，使用符号结论时须另行导入完整非负性模块。
单独通过Packet构建不代表对应符号已完成；高032保留先前的完整模块导入结构。

一般五次式的展开、索引覆盖及所有字段与实际多项式系数的对应分别位于
